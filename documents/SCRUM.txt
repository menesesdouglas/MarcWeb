# 🧩 **Plano de 18 Sprints – Marc Web**

**Objetivo:** sair de *zero* até **produto pronto para venda**
**Estratégia:** backend-first + segurança cedo + frontend leve no final

---

## 🔹 **FASE 1 – Fundação Sólida (Sprints 1–4)**

> Resultado: projeto roda localmente com banco, segurança base e modelo correto

---

### **Sprint 1 – Setup Geral & Infra Local**

**Objetivo:** ambiente 100% funcional

**Entregas**

* Repo Git privado criado
* Spring Boot 3 + Java 17 funcionando
* Maven configurado
* Profiles (`application.yml` e `application-dev.yml`)
* PostgreSQL conectado
* Health check (`/api/health`)

**Tarefas**

* Criar projeto Spring Initializr
* Dependências: Web, Security, JPA, Lombok, Validation
* Estrutura de pastas conforme SDD
* Teste de conexão com banco

✅ *Marco:* `mvn spring-boot:run` sobe sem erro

---

### **Sprint 2 – Modelagem do Banco & Flyway**

**Objetivo:** base de dados definitiva

**Entregas**

* Flyway configurado
* Migration V1 criada
* Todas as 6 tabelas do SDD
* Índices definidos

**Tarefas**

* Criar SQL V1__create_tables.sql
* Configurar Flyway no Spring
* Validar schema no PostgreSQL
* Ajustar constraints e enums

✅ *Marco:* banco recriado automaticamente ao subir app

---

### **Sprint 3 – Entities JPA & Repositories**

**Objetivo:** camada de persistência pronta

**Entregas**

* Entities JPA completas
* Enums mapeados
* Repositories funcionais

**Tarefas**

* Criar User, RegistroPonto, Feriado, Folga, LogAuditoria, ConfigEmpresa
* Mapear relacionamentos
* Criar interfaces JPA
* Testes básicos de persistência

✅ *Marco:* salvar e buscar dados via JPA

---

### **Sprint 4 – Segurança Base (JWT + Roles)**

**Objetivo:** autenticação segura desde o início

**Entregas**

* Spring Security configurado
* JWT funcional (8h)
* BCrypt ativo
* Roles ADMIN / EMPLOYEE

**Tarefas**

* AuthController (login)
* JwtFilter + JwtUtil
* UserDetailsService
* Configuração de rotas públicas/privadas

✅ *Marco:* login retorna JWT válido
