//Cenário de Teste 1: Registro com Geolocalização Ativa - Coordenadas Válidas Dentro do Raio
Objetivo: Verificar se um registro é aceito quando a geolocalização está ativa e as coordenadas fornecidas estão dentro do raio configurado.

Passos:

Configure a Empresa: No banco de dados, certifique-se de que configs_empresa.geoloc_ativa = true, e que lat_centro, long_centro, e raio_geoloc (ex: 100 metros) estejam definidos.
Obtenha um token JWT válido.
Calcule ou escolha coordenadas próximas ao centro da empresa, dentro do raio (ex: a 50 metros).
Configure o Insomnia:
Método: POST
URL: http://localhost:8080/api/registro-ponto/registrar
Headers:
Authorization: Bearer <SEU_TOKEN_JWT>
Content-Type: application/json
Body (JSON):
{
  "tipo": "ENTRADA", // ou o tipo apropriado
  "latitude": -23.5506, // Exemplo: dentro do raio
  "longitude": -46.6334  // Exemplo: dentro do raio
  // Nota: timestamp não é enviado no DTO, o backend usa LocalDateTime.now()
}
Envie a requisição.
Critérios de Sucesso:

O servidor responde com status 200 OK (ou 201 Created).
O registro é salvo com sucesso no banco de dados, contendo as coordenadas fornecidas e o timestamp gerado pelo servidor.
Nenhuma exceção relacionada à geolocalização ocorre no log do servidor.
