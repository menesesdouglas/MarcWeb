# **Software Design Document (SDD) - Marc Web v3.0**  
**Sistema de Ponto Eletrônico Web**  
**Janeiro 2026 - Foco em MVP + Arquitetura Multi-tenant Futura**

---

## **1. Introdução**

### **1.1 Propósito**
Este documento define o design do **Marc Web**, priorizando o **MVP funcional** com arquitetura single-tenant inicialmente, preparando a base para evolução multi-tenant com **Spring Cloud (Eureka + Gateway)** posteriormente.

### **1.2 Estratégia de Desenvolvimento**

#### **Fase MVP (Sprints 1-12):**
- ✅ Desenvolvimento single-tenant completo
- ✅ Foco na lógica de negócio robusta
- ✅ Sistema totalmente funcional para uma empresa
- ✅ Preparação da arquitetura para microserviços

#### **Fase Multi-tenant (Sprints 13-16):**
- 🔄 Refatoração para microserviços
- 🔄 Implementação Eureka + Gateway
- 🔄 Biblioteca compartilhada (common-lib)
- 🔄 Deploy escalável

### **1.3 Funcionalidades Core do MVP**

#### **Prioridade Alta (Sprints 1-12):**
- ✅ Registro de ponto (entrada/saída/descansos)
- ✅ Gestão de funcionários
- ✅ Calendário (feriados + folgas + domingos automáticos)
- ✅ Folha de ponto detalhada (JSON estruturado)
- ✅ Sistema de logs unificado
- ✅ Relatórios mensais com cálculo de horas
- ✅ Exportação PDF
- ✅ Auditoria de ações

#### **Funcionalidades Futuras:**
- 🔄 Contracheque completo (após MVP estável)
- 🔄 Arquitetura multi-tenant com Eureka
- 🔄 Dashboard analytics avançado

## **4. Funcionalidades Detalhadas do MVP**

### **4.1 Registro de Ponto com Validações**

#### **Regras de Negócio:**
1. ✅ **Primeiro registro DEVE ser ENTRADA** (BUG-001 corrigido)
2. ✅ **Sequência obrigatória:** ENTRADA → INICIO_DESCANSO → FIM_DESCANSO → SAIDA
3. 🔄 **Domingos bloqueados** (nenhum registro permitido)
4. 🔄 **Feriados bloqueados** (nenhum registro permitido)
5. 🔄 **Validação de geolocalização** (se ativa)
6. 🔄 **Validação de múltiplos ciclos** (requer justificativa)

#### **Validação de Geolocalização (BUG-003 - Sprint 5):**

```java
@Service
public class RegistroPontoService {
    
    private void validarGeolocalizacao(
        CreateRegistroPonto data, 
        ConfigEmpresa config
    ) {
        if (!config.getGeolocAtiva()) {
            return; // Geoloc desativada, pular validação
        }
        
        if (data.getLatitude() == null || data.getLongitude() == null) {
            throw new GeolocalizacaoObrigatoriaException();
        }
        
        // Calcular distância usando fórmula de Haversine
        double distancia = calcularDistanciaHaversine(
            config.getLatCentro(), 
            config.getLongCentro(),
            data.getLatitude(), 
            data.getLongitude()
        );
        
        if (distancia > config.getRaioGeoloc()) {
            throw new RegistroForaDoRaioException(
                distancia, 
                config.getRaioGeoloc()
            );
        }
    }
    
    private double calcularDistanciaHaversine(
        double lat1, double lon1, 
        double lat2, double lon2
    ) {
        final int R = 6371000; // Raio da Terra em metros
        
        double latDistance = Math.toRadians(lat2 - lat1);
        double lonDistance = Math.toRadians(lon2 - lon1);
        
        double a = Math.sin(latDistance / 2) * Math.sin(latDistance / 2)
                + Math.cos(Math.toRadians(lat1)) 
                * Math.cos(Math.toRadians(lat2))
                * Math.sin(lonDistance / 2) 
                * Math.sin(lonDistance / 2);
        
        double c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
        
        return R * c; // Distância em metros
    }
}
```

### **4.2 Validação de Dia Útil (Sprint 5)**

```java
private void validarDiaUtil(LocalDateTime timestamp) {
    DayOfWeek diaSemana = timestamp.getDayOfWeek();
    LocalDate data = timestamp.toLocalDate();
    
    // Bloquear domingos
    if (diaSemana == DayOfWeek.SUNDAY) {
        throw new RegistroEmDomingoException(
            "Não é permitido registrar ponto aos domingos"
        );
    }
    
    // Bloquear feriados
    if (feriadoRepository.existsByData(data)) {
        Feriado feriado = feriadoRepository.findByData(data).get(0);
        throw new RegistroEmFeriadoException(
            "Hoje é feriado: " + feriado.getNome()
        );
    }
}
```

#### **Endpoint:**

#### **Service:**

```java
@Service
public class FolhaPontoService {
    
    public FolhaPonto gerarFolhaPonto(Long userId, int mes, int ano) {
        User user = userService.findById(userId);
        
        // Buscar todos os registros do mês
        LocalDateTime inicio = LocalDateTime.of(ano, mes, 1, 0, 0);
        LocalDateTime fim = inicio.plusMonths(1).minusSeconds(1);
        
        List<RegistroPonto> registros = 
            registroPontoRepository.findByUserAndTimestampBetween(
                user, inicio, fim
            );
        
        // Buscar feriados e folgas do mês
        LocalDate dataInicio = inicio.toLocalDate();
        LocalDate dataFim = fim.toLocalDate();
        
        List<Feriado> feriados = 
            feriadoRepository.findByDataBetween(dataInicio, dataFim);
        
        List<Folga> folgas = 
            folgaRepository.findByUserAndPeriodo(user, dataInicio, dataFim);
        
        // Gerar JSON estruturado
        JSONObject folhaJson = construirFolhaJson(
            user, mes, ano, registros, feriados, folgas
        );
        
        // Calcular totalizações
        BigDecimal horasTrabalhadas = calcularHorasTrabalhadas(registros);
        BigDecimal horasExtras = calcularHorasExtras(registros);
        
        // Salvar no banco
        FolhaPonto folha = FolhaPonto.builder()
            .user(user)
            .mes(mes)
            .ano(ano)
            .dados(folhaJson.toString())
            .horasTrabalhadas(horasTrabalhadas)
            .horasExtras(horasExtras)
            .diasTrabalhados(calcularDiasTrabalhados(registros))
            .build();
        
        return folhaPontoRepository.save(folha);
```
